## 💻 Quick Embed (HTML / WordPress / Blogger)

Add this responsive iframe code directly into your website's sidebar, blog post, or widget area:

```html
<!-- Start GMP IPO Watch Widget -->
<iframe
  src="https://www.gmpipowatch.in/embed/gmp?rows=8"
  width="100%"
  height="450"
  frameborder="0"
  loading="lazy"
  style="border: 1px solid #e2e8f0; border-radius: 8px; width: 100%; max-width: 600px;"
></iframe>
<p style="font-size: 12px; color: #64748b; margin-top: 4px;">
  Live data powered by <a href="https://www.gmpipowatch.in/" target="_blank" rel="noopener">GMP IPO Watch</a>
</p>
<!-- End GMP IPO Watch Widget -->
```

### Widget Customization Options
You can customize the widget parameters using query strings:
* **All current IPOs (Default):** `https://www.gmpipowatch.in/embed/gmp?rows=8`
* **Mainboard Only:** `https://www.gmpipowatch.in/embed/gmp?board=mainboard`
* **SME Only:** `https://www.gmpipowatch.in/embed/gmp?board=sme`

Configure interactive themes and row counts using the builder at [gmpipowatch.in/embed-widget](https://www.gmpipowatch.in/embed-widget).
